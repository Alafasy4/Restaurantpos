# 🍽️ Restaurant POS System

A native Android Point of Sale (POS) application
designed to simplify restaurant sales management
and daily business operations.

## 📌 Project Overview

Restaurant POS is an Android application developed
to help restaurant owners and staff manage products,
record sales transactions, and monitor daily sales
activities through a simple and organized interface.

The application focuses on simplifying daily
restaurant operations and maintaining structured
local business records.

## ✨ Key Features

- **Product Management**
  - Add and manage restaurant products.
  - Organize product information.
  - Manage product availability.

- **Sales Management**
  - Record sales transactions.
  - Manage sales items.
  - Maintain structured sales records.

- **Daily Reports**
  - Generate daily sales reports.
  - Track daily business performance.
  - Manage daily reporting records.

- **Local Data Management**
  - Store application data locally.
  - Maintain structured records using Room Database.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Kotlin | Primary programming language |
| Android Studio | Development environment |
| Room Database | Local database management |
| SQLite | Database engine |
| Android SDK | Android application development |

## 🏗️ Architecture

The application follows a structured development
approach that separates data management from
the user interface.

Main components include:

- Activities
- Repositories
- Data Access Objects (DAOs)
- Room Database
- Data Models
